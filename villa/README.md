# Villa — Ex の資料配信

このディレクトリは Ex が所有する人間向け資料の表示用コピー。
各情報の正本は元プロジェクトに残す。閲覧は Ex Viewer の Villa を選ぶか `/villa/` から。

ページの追加は HTML と `routes.json` に記述する。既存パスを他の資料で上書きしない。
HTML と route の変更はリクエストごとに読み直すため、配備後のページ追加で再起動は不要。
独立した Python サーバは必要ない。配信コード変更は Ex の通常の配備手順に従う。

2026-09-09 に旧 Villa から追跡済み HTML と URL 対応表を取り込んだ。
旧サービスの停止・旧URL切替は配備後の閲覧確認時に行う。
詳細: `spec/feature/unified-viewer.md`。
