セッション消費レポートの
算式と近似

Villa のセッション消費レポートが、ネイティブ JSONL の token 使用量をどのように等価 API コストへ換算するかを説明します。

消費レポートを開く Villa の一覧へ戻る
これは実請求額ではありません。 Claude / Codex ともサブスクリプション利用のため、表示する USD はモデル間・セッション間の利用量を比較するための等価 API コストです。20x 枠の消費率や枯渇時刻は別途追跡すべき運用指標です。

1. 集計対象と共通ルール

  • 対象期間はレポートに表示した JST の7日間です。
  • セッション・モデル / effort・日付別の表は、同じ元データから集計します。推定 USD は3つの表で必ず合計が一致するよう検証します。
  • 未単価モデルを無言で $0 として扱いません。代理スケールを設定した場合は、表の「コスト根拠」に明示します。
  • 価格スケールの正本は Concordia の src/cost/price-table.ts です。この資料はその人間向け説明であり、価格の正本ではありません。

2. Claude Code の集計

入力ログと重複除去

Claude Code のネイティブ JSONL にある message.usage を読みます。同じ応答を二重に数えないため、まず message.id、無い場合だけ行の uuid で重複を除きます。

トークンと式

次の token 内訳を使います。単価は USD / 100万 tokens です。

USD = (
  input × inputPrice
  + output × outputPrice
  + cacheRead × inputPrice × 0.1
  + cacheWrite5m × inputPrice × 1.25
  + cacheWrite1h × inputPrice × 2.0
) / 1,000,000

3. Codex の集計

入力ログと期間確定値

Codex のネイティブ JSONL にある event_msg.payload.type = "token_count" の info.total_token_usage を使います。ここにはスレッド累積の input_tokens、cached_input_tokens、output_tokens、total_tokens が入ります。

同じ Codex JSONL はレポート作成後にも追記されます。そのため、期間内の総 tokens はレポート確定時の値を正本にし、後から読める JSONL は入力・出力・cache の比率を得るためだけに使います。

トークンと式

uncachedInput = max(input - cachedInput, 0)

USD = (
  uncachedInput × inputPrice
  + cachedInput × inputPrice × 0.1
  + output × outputPrice
) / 1,000,000

sessionUSD = USD(log の内訳) × reportTokens / logTokens

Codex ログでは cache 書き込みの保持時間内訳がないため、Claude の cache write 係数は適用しません。キャッシュ入力は代理入力単価の 0.1 倍とします。

JSONL が残っていないセッション

期間確定後にローカル JSONL がなくなった Codex セッションは、同じ model と effort で内訳を取れたセッションの平均 USD / token を適用します。レポートでは「同 model/effort 平均」と表示します。現在の集計では 7 セッションがこの補完に該当します。

4. 日付別への配賦

Codex はスレッド累積値であり、セッションが日をまたぐことがあります。セッション・モデル / effort 別の確定概算を日付別に表示する際は、レポートの確定済み日別 token 構成比で配賦します。これにより、日付別の合計もセッション別・モデル別の合計と一致します。

5. どう読むか

  • 比較には使える: 同じ期間内で、どの provider / model / effort が利用量を大きく占めたかを比較できます。
  • 請求書には使えない: サブスクの実支払額、API の実請求、20x 枠の残量をこの USD から逆算してはいけません。
  • 20x 運用には別指標: 20x の消費率、現在の残枠、枯渇予測時刻は、サービスが提供する quota / usage の一次情報で別に管理します。
  • 近似は更新可能: 実価格やモデル階層について新しい一次情報が得られたら、代理スケールを更新し、レポートとこの資料の両方へ反映します。
このページは Villa の人間向け説明資料です。数値の正本は各 provider のネイティブ JSONL と、価格スケールの正本です。
